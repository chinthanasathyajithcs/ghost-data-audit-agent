## What the cold runs found

Running from empty caches was worth more than a usage number: two cold runs exposed run-to-run LLM
variance that cached reruns hide (the cache freezes whatever the first run decides).

| Cold run | Variance | Fix |
|---|---|---|
| 1 | Screenshot extraction omitted a screen header (a wrong catalog claim was accepted, eval case_63) and turned a panel reference into a record (case_34) | Extraction prompt requires header identity fields and keeps references as fields; marketing screen added to the truth set; bake-off 70/70 (Stage 4 §7.2.1) |
| 2 | One thin support-ticket signature classified as a secondary identifier, flipping 7 tickets to delete | Majority vote of three answers per category batch; sharper secondary-identifier rule (Stage 6 §7.3.1) |
| 3 (final) | None: output identical to the validated version; every suite unchanged | — |
